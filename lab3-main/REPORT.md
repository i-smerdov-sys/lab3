# Отчёт по лабораторной №3: линейные модели

## 1. Данные и подготовка

В лабораторной работе использовались два набора данных: `Student_Performance.csv` для регрессии и `german.csv` для бинарной классификации.

**Student Performance:**
- Количество объектов: 10 000.
- Количество столбцов: 6.
- Целевая переменная: `Performance Index`.
- Количество признаков: 5.

Столбец `Extracurricular Activities` преобразован в числовой формат: `Yes` — 1, `No` — 0. Данные разделены на обучающую и тестовую выборки в соотношении 80/20 с `random_state=42`. Получено 8 000 обучающих и 2 000 тестовых объектов.

**German Credit:**
- Количество объектов: 1 000.
- Количество столбцов: 21.
- Целевая переменная: `Creditability`.
- Количество признаков: 20.

Данные загружены с разделителем `;`. Целевая переменная проверена на наличие только двух классов: 0 и 1. Разделение выполнено в соотношении 80/20 с параметрами `random_state=42` и `stratify=y_clf`. Получено 800 обучающих и 200 тестовых объектов.

Для собственной логистической регрессии признаки стандартизировались по обучающей выборке. Для библиотечной логистической регрессии и KNN использовался `StandardScaler`. Дерево решений обучалось без стандартизации.

## 2. Гипотезы и эксперименты

В работе проверялись три гипотезы:

1. Собственная линейная регрессия с градиентным спуском сможет достаточно точно предсказывать `Performance Index`.
2. Собственная логистическая регрессия сможет решать задачу бинарной классификации с качеством, близким к реализации scikit-learn.
3. Логистическая регрессия сможет показать лучшие результаты по сравнению с деревом решений и KNN.

**Линейная регрессия**

Реализована на NumPy с использованием пакетного градиентного спуска. Применялись стандартизация признаков и целевой переменной, вычисление MSE и обновление весов.

Параметры:
- `learning_rate = 0.05`;
- `epochs = 800`;
- функция потерь: MSE.

**Логистическая регрессия**

Реализована самостоятельно с использованием сигмоидальной функции, Binary Cross-Entropy и пакетного градиентного спуска.

Параметры:
- `learning_rate = 0.1`;
- `epochs = 1000`;
- порог классификации: `0.5`.

Для сравнения использовались четыре модели: собственная логистическая регрессия, `LogisticRegression`, `DecisionTreeClassifier` и `KNeighborsClassifier`.

Все модели обучались и тестировались на одном разбиении данных.

## 3. Метрики

### 3.1. Линейная регрессия

Качество оценивалось с помощью среднеквадратичной ошибки MSE.

| Метрика | Результат |
|---|---:|
| Test MSE | **4.082628** |

### 3.2. Сравнение моделей классификации

Для оценки использовались ROC-AUC, Accuracy, Precision, Recall и F1-score.

| Модель | ROC-AUC | Accuracy | Precision | Recall | F1-score |
|---|---:|---:|---:|---:|---:|
| Собственная логистическая регрессия | 0.8081 | 0.77 | 0.8013 | 0.8929 | 0.8446 |
| LogisticRegression (sklearn) | 0.8086 | 0.77 | 0.8013 | 0.8929 | 0.8446 |
| DecisionTreeClassifier | 0.6190 | 0.68 | 0.7714 | 0.7714 | 0.7714 |
| KNeighborsClassifier | 0.7412 | 0.72 | 0.7692 | 0.8571 | 0.8108 |

**Анализ результатов:**

Собственная логистическая регрессия показала практически такие же результаты, как библиотечная реализация scikit-learn. Разница ROC-AUC составила всего 0.000476, остальные метрики совпали.

Дерево решений показало худший результат: Accuracy — 0.68, ROC-AUC — 0.6190. Вероятная причина — чувствительность одиночного дерева к особенностям обучающей выборки.

KNN показал промежуточный результат с Accuracy 0.72 и Recall 0.8571, однако уступил логистической регрессии по всем пяти метрикам.

## 4. Выводы

В ходе лабораторной работы были самостоятельно реализованы линейная и логистическая регрессии с использованием NumPy и градиентного спуска.

По результатам экспериментов:

1. Линейная регрессия показала Test MSE **4.082628**.
2. Собственная логистическая регрессия достигла ROC-AUC **0.8081** и Accuracy **0.77**.
3. Результаты собственной и библиотечной логистических регрессий практически совпали.
4. Дерево решений показало наименьшее качество классификации.
5. KNN оказался лучше дерева решений, но уступил логистической регрессии.

Таким образом, лучшей моделью классификации на выбранном наборе данных оказалась логистическая регрессия. Эксперимент подтвердил, что собственная реализация градиентного спуска способна показывать результаты, близкие к библиотечной модели scikit-learn.

## 5. Воспроизводимость

Для работы использовались библиотеки:
- `NumPy` — математические вычисления и градиентный спуск.
- `Pandas` — загрузка и обработка данных.
- `scikit-learn` — классические модели, стандартизация и метрики.
- `json` — сохранение результатов.

Основные параметры экспериментов:

| Параметр | Линейная регрессия | Логистическая регрессия |
|---|---:|---:|
| Learning rate | 0.05 | 0.1 |
| Epochs | 800 | 1000 |
| Функция потерь | MSE | Binary Cross-Entropy |

Дополнительные параметры:
- Размер тестовой выборки: 20%.
- `random_state = 42`.
- `stratify = y_clf` для классификации.
- `n_neighbors = 5` для KNN.
- `max_iter = 2000` для LogisticRegression.

Результаты сохраняются в `experiment_results.json`.

Для повторного запуска необходимо поместить оба CSV-файла в рабочую директорию, установить NumPy, Pandas и scikit-learn и выполнить:

`python run_experiments.py`

Все результаты получены на исходных наборах данных с фиксированными параметрами разделения и обучения.
